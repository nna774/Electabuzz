**買ってはいけないもの**

- **入力がワイドレンジ(90〜264V)のACアダプタ。** 中身がスイッチングで波形が再構成されており、
  測定対象にならない
- **Ideal Power 77DS-06-12。** 中身は正しいが豪州プラグなので日本の壁コンセントに挿さらない
- **GPSDO(GPS規正10MHz発振器)。** 方式Aは局部発振器の誤差を一次で相殺するので、
  数千〜数万円払って得るものが何もない
- **モジュール付属のセラミックパッチアンテナだけで済ませること。** 屋内では fix しない。
  アクティブアンテナ代を節約すると全体が動かない

AWS はスタックを分けても追加費用ほぼゼロ(S3 にバケット単位課金はなく、Lambda に
アイドル課金はない)。永久保存 380MB/年の S3 コストは月数円、
Lambda 実行は既存より軽い。
