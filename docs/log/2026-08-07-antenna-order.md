# アクティブアンテナを発注した

**GPS+BD+GLONASS対応のアクティブアンテナを2本、AliExpressで発注した。** 販売元は XYANT
Offical Store（ブランド表記は NOWEPOCH）、「GPS+BD+GLONASS Antenna」、SMA Male、
836円/本 × 2 = 1,672円（1,500円以上で送料無料）。

## 選定した理由

- 現物ラベル画像で確認: `Frequency: 1561-1608MHz`。GPS L1(1575.42MHz)・
  GLONASS L1(1598-1606MHz)・BeiDou B1(1561MHz) を単一帯域でカバーしており、
  [gnss.md](../gnss.md) の要件（GPS/GLONASS 両対応・SMA・2,000〜3,000円）を満たす
- 3m の RG174 ケーブル、平たいパッチ形状（46×39×13.5mm）。磁石マウントではなく
  貼り付け前提の筐体で、**磁石が付かない窓ガラスへの直接貼り付けにむしろ向く**
- レビューに実使用報告があった: 「窓際に置いて neo-m10 につないだら34個受信して、
  26個使用になっている」——u-blox NEO系受信機・窓際設置という本件と同条件での
  実測報告が既にあり、裏取りとして強い

## 却下した候補と、そこから得た購入判断の教訓

検討中に「安いが条件を満たさない」候補を複数踏んだ。今後の部品選定にも使えるので
教訓として残す。

- **GPS 単一周波数のみの品を2件掴みかけた**（uxcell の磁気マウント品、
  「NEO-8M NEO-7M...」481円品）。**いずれもタイトルやAI生成の商品概要は
  対応を匂わせるが、現物ラベルの周波数表記を見ると 1575.42MHz 単体だった。**
  GLONASS帯（1598〜1606MHz）の記載が無いものは GPS 専用と判断してよい
- **「L1/L2/L5」「マルチ周波数」を謳う RTK 向け品は避けた**（JINYUSHI 社の
  上位モデル、AliExpress の 28dBi 表記品など）。**NEO-M8N は単一周波数(L1)
  受信機なので、L2/L5 対応は完全に無駄になる。** 同じ商品ラインでも型番違い
  （W50A/W50C/W55D/W60D/W70D 等）で下位モデルが L1 専用のことがあり、
  **「AIによる商品概要」は商品ライン全体をまとめて誤って要約することがあるので、
  個別の仕様画像（現物ラベル）を必ず確認すること**
- **「28dBi」等、物理的にあり得ないアンテナ利得表記は疑ってよい**
  （アンテナの指向性利得 dBi と LNA 増幅率 dB の混同。実際は LNA ゲイン
  28〜33dB 程度が正しい表記）
- **タイトルのキーワード詰めと「AIによる商品概要」は信用度が低い。**
  商品説明文がテンプレート流用で実物と無関係な場合がある（別の商品ページで
  IC部品の説明文が紛れ込んでいた例があった）。**判断材料は現物写真に写った
  ラベルの実測風の記載にすること**

## 2本にした理由

窓の面積は制約にならないと判断し、送料無料ライン（1,500円）に乗せる意味も込めて
2本発注した。**2台目の GNSS 受信機を買う計画があるわけではない**
（[open-questions.md](../open-questions.md) の通り、2台目は段階1の判定後に決める
既定路線のまま）。**今回の2本目は当面使わない予備部品**——配線中の破損に備えた
予備、および将来もし2系統目（NTPサーバとの共用等、[gnss.md](../gnss.md) の
「GPS由来NTPサーバとの共用」節にある別プロジェクト）が要る場合の下ごしらえとして
確保した。

なお、この経緯で「アンテナ1本+専用スプリッタ」より「安い L1 アンテナを複数本」の
方が総コストが低い可能性に気づいた（スプリッタは $30〜50 する一方、このアンテナは
1本 836円）。ただし NTP サーバ共用プロジェクト自体がまだ着手されていないため、
[gnss.md](../gnss.md) の「アンテナは共有すべき」という結論をこの場では書き換えない。
その別プロジェクトが実際に動き出した時に再検討する。
