# Vcc/2バイアス網を不要と確定し、OPアンプ選定の宿題を消す

## やったこと

`open-questions.md`に残っていた「DMMが届いたらモジュール入力のDC電位を測る」を
実行した。DMMをDC電圧レンジにして、AFE分圧の出力点(node A、PCM1808のL INに
繋がる点)とGNDの間を測定。結果は**数mV(ほぼ0V)**。

## 分かったこと

外側のパッド(node A)が分圧網(R2→GND)の電位そのままだったということは、
**モジュール側は外部パッドまで独自バイアスを引き出していない**。同日確認した
50Hz波形（→ [2026-08-07-gridfreq-test-mode.md](2026-08-07-gridfreq-test-mode.md)。
THD 0.0%、片側クリップ無し、綺麗な正弦波）と合わせて考えると、**PCM1808 チップ
内部(電解コンデンサでAC結合された向こう側)が自己バイアスできている**と判断できる。

`hardware.md`が条件付きで書いていた「モジュール側がVREF=0.5VCCへバイアスして
いるなら、Vcc/2バイアス網は要らない」の条件が満たされた。**Vcc/2バイアス網は
不要と確定した。**

### 副産物: OPアンプが要る理由が両方消えた

`hardware.md`はC1を「Sallen-Key(2次・要OPアンプ)」として設計していたが、
その理由を遡ると2つしかない: ①急峻なアンチエイリアスフィルタが欲しい
②Vcc/2バイアスを低インピーダンスで供給したい。

①は元から「単一ビンDFTが高調波を除去するので急峻さは不要」と`hardware.md`
自身が書いており、成立していなかった。②は今回の実測で不要と確定した。
**両方消えたので、OPアンプそのものが要らなくなった。**

C1は受動1次RC(node AからGNDへコンデンサ1個)で代替できる見込み。現在の分圧網
(R1=100kΩ・R2=6.8kΩ・PCM1808入力≈60kΩ)から見た実効抵抗は

```
R_eff = 1 / (1/100k + 1/6.8k + 1/60k) ≈ 5.76kΩ
```

fc≈1.5kHz(元の設計目標)を狙うなら C ≈ 1/(2π·fc·R_eff) ≈ 18nF(E24で15〜22nF)。
50Hzでの位相シフトは`arctan(50/1500)=1.9°`の固定値で、PCM1808内蔵HPFの
1.045°と同じ理屈(定数位相は微分でゼロになる)で無視できる。

**TVS(サージ・雷サージ対策)はコンデンサでは代替できない別枠の課題として残る。**

## 覆ったこと

`docs/hardware.md`のAFE回路図から`Vcc/2バイアス`のブロックを削除し、C1を
「2次Sallen-Key」から「受動1次RC」に書き換えた。`bom.md`のAFE部品行から
OPアンプを外し、C1用コンデンサ+TVSのみに整理した。

## 次に何が可能になったか

C1(≈15〜22nF、E24)を実際に配線して、今日見えていたノイズ(l_pp/r_ppのフルスケール
張り付き、gridfreqテストでの89〜109Hz帯エイリアシング)が収まるか確認できる。
まだ**机上の見立てで、実配線・実測はしていない。**
