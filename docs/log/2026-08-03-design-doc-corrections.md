# 2026-08-03: 設計書初期版で覆った判断（ログ分割前のぶんの回収）

設計書が1本の巨大ドキュメントだった時期に覆った判断のうち、**まだどのログにも
書かれていなかったもの**をここに移す。本体側の `> **訂正**:` 枠はこれをもって削除した。

**なぜ移すか。** `docs/*.md` は現在の結論、`log/` は経緯 — この役割分担が崩れると、
読む側が毎回「どちらが今の話か」を判定させられる。ただし**意図的に採らなかった選択肢は
本体に残す**（消すと同じ提案が再浮上する）。残すときは履歴としてではなく
**「なぜ採らないか」という肯定文**で書く。それが判断であって経緯ではないからだ。

---

## 1. 「`Batch` の先頭32バイトを変えるな」という制約は存在しなかった

**書いていたこと**: `Batch::fromBytes()` が offset 8/20 を直読みするので、`NAMZ` v1 の
32バイトヘッダを維持し、拡張は後ろに追記せよ。

**なぜ誤りか**: `fromBytes` は `src`/`lib` 全体を grep して**呼び出し元がゼロの死んだコード**
だった。LittleFS の退避・復元は `bytes()`/`size()` を生バイト列として書き、読み戻して
`postBatch()` へ直接渡し、順序は**ファイル名から `strtoull`** で復元する。
**ヘッダを一度もパースしていない。**

**何が変わったか**: `Electabuzz` はヘッダを自由に設計できる。これが `GFRQ` を
「v1 の32バイト + 拡張32バイト」ではなく**単一の64バイトヘッダ**として引き直せた前提であり、
`Batch` からワイヤ形式の知識を完全に抜く方針の根拠にもなった。
→ [wire-format.md](../wire-format.md)

**教訓**: **死んだコードに設計を縛らせるな。** 制約を見つけたら、まず呼び出し元を数えろ。

## 2. `lib/Display` は共有対象ではなかった

**書いていたこと**: 表示層は両者で共有できる。

**なぜ誤りか**: 実物は `ClassFont.h` が580行の**震度クラス専用の字形テーブル**で、
TFT_eSPI にも依存していた。

**教訓**: **過剰に切り出すな。** 「名前が汎用的」と「中身が汎用的」は別だ。
`batch-uplink` に何を入れるかの線引き（ドメインが混ざった瞬間に共有ライブラリとしての
価値が消える）は、この一件から来ている。

## 3. NEO-M8T の価格見積りが1桁違っていた

**書いていたこと**: M8T のブレイクアウトは 4,000〜6,000円。

**実際**: **$100 前後。**

**何が変わったか**: 判断そのものが変わった。**未測定のリスクに1万円の保険を先払いするのは
順序が逆**なので、「安価なモジュールで空の見え方を実測してから M8T の要否を決める」という
段階購入に組み直した。校正用の2台目も、M8T ではなく安価なモジュール（1,000〜2,500円）で
足りると分かった。→ [gnss.md](../gnss.md), [verification.md](../verification.md)

**教訓**: **部品の価格は「判断を変える入力」だ。** 概算のまま設計を進めるな。

## 4. 「Pi を第2系として並行稼働させる」は勝手に導入した前提だった

**書いていたこと**: Pi + GNSS + chrony は stratum-1 NTP サーバであり、同じ Pi に I2S ADC を
足せば第2系の周波数測定になる。1台で両方の目的が満たされる。

**なぜ誤りか**: **二重測定の計画などそもそも無かった。** わがはいが勝手に前提を置き、
その上で議論を組み立てていた。Pi は「ESP32 で立ち上がらなかった場合の**代替母艦**」として
検討していたにすぎない。

**何が変わったか**: **二重測定に依存しない検証手段**（TP2 自己校正 + 外部照合）に
[verification.md](../verification.md) を組み直した。結果として検証計画は Pi の有無から独立した。

**教訓**: **前提を導入したら、それが要求由来か自分由来かを明示しろ。**
自分で置いた前提の上に積み上げた議論は、前提ごと崩れる。

## 5. トランスの出力電圧を1ランク上げても励磁は軽くならない

**書いていたこと**: 50Hz 地域なら1ランク上の出力電圧品を選べば励磁が軽くなる。

**なぜ誤りか**: 77DA-12-xy は**全型番で一次側が同じ 120V 巻線**なので、磁束は二次側の
出力電圧の選択に**一切依存しない**。飽和余裕は型番を変えても変わらない。

**何が変わったか**: 磁束を下げたいなら**一次が 100V 系の 50Hz 定格品**に行くしかない
（ただしプラグ形状が全滅する）。実際には DA-12-09 の1時間通電が合格したので、この道は不要になった。
→ [hardware.md](../hardware.md)

**教訓**: **磁束は一次側で決まる。** 二次側の型番違いに意味を求めるな。
