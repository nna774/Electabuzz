# dashboardの「PPS未着」キャプションを現状に合わせて修正

`dashboard/index.html` の周波数グラフ直下の説明文が「PPS未着のためGNSS品質ではなく
NTP品質」という、PPSハードウェアがまだ配線・実装されていなかった頃の記述のまま残って
いた。フェーズ2は2026-08-15に実配線・初回ロックに成功しており（残差30ns/s。
[docs/log/2026-08-15-phase2-pps-first-lock.md](2026-08-15-phase2-pps-first-lock.md)）、
「PPSが未着」という表現はもう実態と合わない。

現状は「PPSロック自体は実機で成功しているが、soak確認・クラウド着弾確認がまだのため、
クラウドに届いているのは今のところNTP品質のデータのみ」というのが正確な状態
（→ [docs/progress.md](../progress.md) 冒頭の「現在の状態」参照）。キャプションをこの
内容に書き換えた。時刻偏差の絶対値をまだ出せない、という結論自体は変わっていない。

設計判断の変更はなし。表示文言のみの修正。
