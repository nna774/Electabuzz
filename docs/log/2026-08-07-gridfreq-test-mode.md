# NAMZ_GRIDFREQ_TESTで50Hzの疎通を確認する

## やったこと

`docs/roadmap.md` フェーズ1で予告されていた「`NAMZ_SENSOR_TEST`と同じパターンで
`NAMZ_GRIDFREQ_TEST`ビルドフラグを作り、シリアルに生サンプルを吐く」を実装した。
Namazu(`NamazuHaUrokoGaNai/firmware/src/main.cpp`)の`NAMZ_SENSOR_TEST`と同じ位置付け
——WiFi/NTP/fs回帰を一切やらず、I2Sの生サンプルをシリアルに吐くだけの使い捨てモード。

- `firmware/src/main.cpp`: `#ifdef NAMZ_GRIDFREQ_TEST`で`setup()`/`loop()`を丸ごと
  分岐。48kHzの生サンプルはそのままだとシリアル(115200baud)の帯域を超えるので、
  boxcar平均で間引いてから吐く（Namazuの地震計がオーバーサンプル平均で使っている
  のと同じ手法）
- `firmware/platformio.ini`: `[env:gridfreqtest]`を追加
- `tools/capture_serial.py`（新規）: Namazu版と同じ形でシリアルCSVを保存
- `tools/spectrum.py`（新規）: FFTで卓越周波数とTHDを見る＋ゼロクロス法で瞬時周波数の
  時系列を作る。numpyが要るので`.venv`に追加した（Namazu側の`.venv`には既にある）

## 分かったこと

### 1. タイムスタンプにバグがあった（バースト処理を実時刻と取り違えた）

最初の実装は各サンプルの時刻に`ticksNow()`（壁時計）を使っていた。だが`i2s_read()`
は512フレーム（≈10.7ms）ぶんをDMAがまとめて返してくる。**その場で`ticksNow()`を
呼ぶと、1回の`i2s_read`の中で処理した数点がほぼ同時刻を指し、次の`read`までの
本来の間隔がその1点に丸め込まれる**。実際、間引き48（公称実効1000Hz）で取った
キャプチャを解析すると、実測の実効fsが20833Hzという明らかにおかしい値になった。

**フレームカウンタ起点の仮想時刻**（`frameIdx * 1e6 / kFsNominalHz`）に直したところ、
実効fsがぴったり公称値(1000Hz→間引き200では240Hz)に一致するようになった。

### 2. C1(LPF)未実装のノイズが間引きをすり抜けてエイリアシングした

タイムスタンプ修正後、間引き48（実効1000Hz）で再取得すると、スペクトルの卓越
周波数が89〜109Hz帯に出た。50Hzではない。boxcar平均は48000/48=1000Hzに最初の
ヌルを持つsinc型のフィルタだが、減衰は緩やか(最初のサイドローブで-13dB程度)で、
C1未実装のハイインピーダンスノードに乗っている広帯域ノイズを十分には落とせて
いなかったと判断した（→ [2026-08-07-fs-wiring-verification.md](2026-08-07-fs-wiring-verification.md)
で確認済みの、同じノイズ源）。

間引きを48→200（実効1000Hz→240Hz）に伸ばしたところ、50.03Hz付近に明瞭なピークが
立ち、他を圧倒するようになった。無相関ノイズは平均本数を伸ばすほど`1/√N`で
下がる一方、50Hzの周期(20ms)よりずっと短い窓(200サンプル≈4.2ms)なら本命信号は
ほとんど減衰しない——狙い通りの結果。

### 3. 50Hzの疎通を確認した

60秒キャプチャ(n=14401、実効fs=239.98Hz)の結果:

- FFT基本波(40-60Hz帯内最大): 50.026Hz、THD(2-7次) 0.0%
- ゼロクロス法: n=2983点中2983点(100%)がバンド内、中央値49.934Hz、std=0.3041Hz

配線から実際に50Hzの商用電源波形が拾えていることが確認できた。ただし**これは
`docs/roadmap.md`フェーズ3のGoertzel位相推定ではなく、GNSS較正も無い粗いチェック**。
TE級の精度は主張しない。

### 4. 可視化: 生点のままだと帯状に潰れる

ゼロクロス点(1周期=1点、60秒で約2983点)をそのまま折れ線にすると、時間軸1pxに
複数点のジッタが乗って塗り潰しに見える（ユーザー指摘）。**0.5秒窓でビン分けし、
窓内のmin-maxを帯、平均を線**にして描き直した。ジッタを隠さずにトレンドが
読めるようにする狙い。
