# 段階1の GNSS 受信機（NEO-M8N）を発注した

## 何を買ったか

u-blox NEO-M8N ブレイクアウト（基板 silk `HW-542`）を1枚。**1,629円、アンテナ無し版。**

- 商品: https://ja.aliexpress.com/item/1005006274202366.html （バリエーション `NEO-M8N`）

現物確認は商品写真の silk を読んで行った。

| 要件 | 判定 |
|---|---|
| **PPS がパッドに出ている** | **○** ピンヘッダが `PPS RXD TXD GND VCC` |
| **u-blox である** | **○**（裏面刻印 `NEO-M8N-0-10`） |
| **QZSS 対応** | **○** M8 世代 |
| 外部アンテナに替えられる | **◎** IPEX と **SMA の両方**が載っている |
| 価格 | 段階1の予算（1,000〜2,500円）に収まる |

**想定していなかった収穫が2つあった。**

- **EEPROM が載っている。** `CFG-TP5`（fix 喪失時も TIMEPULSE を出させる）と
  `CFG-NAV5`（定置モード）が**電源を切っても残る**。設定が揮発する基板だと
  毎起動で投げ直す運用になるので、これは効く
- バックアップ電池も載っている（起動が速くなるだけだが、無いよりよい）

## なぜ M8N か（世代の選定）

詳細は [gnss.md](../gnss.md) に本体として書いた。要点だけ:
**QZSS 対応**（準天頂軌道 = 窓際で効くのは高仰角の衛星）、**同時受信**（狭い空で
衛星数を稼ぐ唯一の方法）、**M8T と同世代**（段階3へ設定の知見がそのまま繋がる）。

NEO-6M は QZSS 非対応で外した。M9N は設定インタフェースが `VALSET`/`VALGET` に
変わっており段階1の知見が段階3で使えない上、**M8T の代替にもならない**
（M8T の値打ちは受信性能ではなく 0D モード）。

## 引っかかった点（届いてから潰す）

- **モジュール天面に u-blox ロゴが見えない。** 正規品は金属シールドにロゴと型番が
  レーザー刻印されている。加工された商品写真の可能性もあるので断定はしないが、
  **この価格帯の「M8N」には偽物・別チップの張り替えが混ざる**
- **SKU の内部名が `NEO-8N`** になっている。u-blox にその型番は無い（正しくは `NEO-M8N`）
- 出品タイトルに `NEO-6M` `NEO-7M` `NEO-M8N` の3つが並んでいる。
  ただし**バリエーションごとに写真が分かれ、選んだものの基板が写っていた**ので、
  キーワード詰めではなく素直な多バリエーション出品だと判断した
  （Amazon で ATGM336H を NEO-M8N と誤認しかけた件とは別物）

**届いたら `UBX-MON-VER` を投げて版を読め。** そこで初めて本物と確認できる。

## まだ足りないもの

**アクティブアンテナを買っていない。** この基板には付いてこない。
**GPS/GLONASS 両対応**のもの + SMA + 3〜5m ケーブル、2,000〜3,000円。
GPS 専用品を掴むと **M8N を選んだ理由である同時受信が無駄になる**（GLONASS L1 は
1598〜1606MHz で GPS の 1575.42MHz とは帯域が違う）。→ [gnss.md](../gnss.md)

**受信機はもう1台要る**（別プロジェクトの NTP サーバ用。1台を2機で分けるなという
判断は [gnss.md](../gnss.md) にある）。ただし**急がない** — 段階1の判定が出てから、
M8N をもう1枚にするか M8T にするかを決めればよい。

なお、この基板が SMA にアンテナ用のバイアス電圧を出しているかは写真から確認できて
いない。同出品の `+antenna` 版が付けているのがアクティブアンテナなので出ていると
見ているが、**これは推測である。** 届いたら実測しろ。

## 何が次に可能になるか

到着後、**数日ログを取って捕捉衛星数と fix 安定性を実測する。**
これが「NEO-M8T（約$100）を買うか否か」の判定そのものだ（→ [gnss.md](../gnss.md) 段階2）。

**ただしアンテナが揃うまで判定は始められない。** 段階1が測っているのは受信機の性能
ではなく**空の見え方**であり、それを決めるのはアンテナと設置場所だからだ。
モジュール単体で先に測っても、その数字には意味が無い。
