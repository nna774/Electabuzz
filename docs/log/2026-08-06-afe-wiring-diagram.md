# 2026-08-06 実配線用の配線図を作り、AC出力の戻り端子の欠落に気づいた

配線して `fs` を実測する段になり、`hardware.md` の文章と表だけでは実際に手を動かすには
足りなかった。AFE（R1=100kΩ/R2=6.8kΩ）・電源（5V/3.3Vの2系統）・I2Sピン割り当て
（MCLK=16, BCK=17, LRCK=18, DIN=15）を1枚にまとめた配線図を作った。

## 分かったこと

配線図を描く過程で、AC出力（バレルジャック）の扱いに欠落があると分かった。
バレルジャックの2端子はどちらもAC（トランス二次巻線の両端）で、あらかじめGND電位に
決まっている端子は無い。ところが既存の図はR1に繋ぐ信号側の1本しか描いておらず、
もう一方の端子（戻り側）をどう扱うかがどこにも書かれていなかった。「配線図を出す」
という具体的な要求があって初めて、文章の記述だけでは埋まらない抜けが見えた形になる。

## 決めたこと

- `docs/hardware.md` の配線図に、戻り端子は回路GND（ESP32のGNDと同じ）へ直結する旨と、
  絶縁トランス越しである以上どちらの端子を基準に取っても安全性は変わらない理由を明記した
  （コミット `cd555d2`）
- 実配線用の配線図をArtifactとして公開した:
  https://claude.ai/code/artifact/21ca85ea-e4a8-44f2-b652-cd17a58bda22
  （確定/未確定をチップで区別。AFE・電源・I2Sの3セクション。TVS/C1(LPF)/Vcc/2バイアスは
  未確定のままダッシュ枠で残した）

## 次に何が可能になったこと

配線図と`hardware.md`の戻り端子の記述が揃ったので、実配線に迷う点は無くなった。
残る「配線して`fs`を実測する」の着手を妨げるものは無い。
