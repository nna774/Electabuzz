# 2026-08-05 オンボード RGB LED を色相インジケータに使う案

手元の母艦（ESP32-S3-WROOM-1 N16R8 のクローンボード）に、デフォルトファームで
虹色にぐるぐる回るデモが焼かれていた。これは基板上の WS2812 互換アドレサブル
RGB LED 1個によるもの。

## 分かったこと

- **物理的に回る意匠ではない。** LED は1個だけなので、リング状に光が移動する
  ような表現はこの部品単体では作れない。できるのは色相（hue）を時間軸で
  回すことだけ
- 販売ページ（AliExpress の商品説明・仕様欄）には LED の駆動 GPIO の記載が無い。
  Espressif 純正 DevKitC-1 系だとリビジョンにより GPIO38 か GPIO48 が定番だが、
  この個体は互換品でありそのまま当てはまる保証はない

## 決めたこと

- **使うなら色相回転で。** 物理回転ではなく、`residual_ns` や周波数偏差などの
  量に応じて色相の回転速度を変える方向で検討する。実装はまだしない
- **どの GPIO かは今は確認しない。** 今この基板は
  [フェーズ1.5 の soak](2026-08-04-soak-running.md) が走行中で、繋ぎ直すと
  `NtpTimebase` の回帰が積み直しになる。soak が一段落してから、
  `Adafruit_NeoPixel` のサンプルで GPIO38 / GPIO48 あたりを順に試して特定する

余っているものを使う程度の優先度であり、コア機能（時間基準・位相推定）には
関係しない。soak の結果を読む作業を妨げてまで急ぐ理由は無い。
