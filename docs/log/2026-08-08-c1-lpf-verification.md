# C1(LPF)を実装し、受動1次RC・15nFで確定した

## 決めたこと

AFEのC1(アンチエイリアス用LPF)を**15nF(セラミック、表示コード`153`)の受動1次RC**として
実装し、`env:gridfreqtest`を焼いて実測で効果を確認した。ノードA(R1/R2接続点、
PCM1808 L INへの配線元)からGNDへ、R2と並列に接続した。

`docs/hardware.md`で「未確定」としていたC1の定数がこれで確定する。

## なぜ15nFか

分圧網(R1=100kΩ・R2=6.8kΩ・ADC入力≈60kΩ)から見た実効抵抗 R_eff≈5.76kΩ、
目標fc≈1.5kHzから逆算した計算値は18nF(E24系列)だったが、手元にあったのは
`153`(15nF)表示品だった。15nFは許容範囲(15〜22nF)の下限に当たり、fcは
1/(2π·5.76kΩ·15nF)≈1.84kHzとやや高めに出るが、50Hzでの位相シフトは
`arctan(50/1840)≈1.6°`の固定値で時間微分するとゼロになるため実害はない。
**在庫にあった値をそのまま採用し、計算値ぴったりの18nFを別途探す手間はかけなかった。**

## 何が確認できたか

`env:gridfreqtest`を焼き直し、`/dev/cu.usbmodem5CCD0331811`(CH343ブリッジ)から
30秒キャプチャした(`tools/capture_serial.py` → `tools/spectrum.py`)。

- **クリッピング消失**: 7202サンプル中、フルスケール99%以上に張り付いた点は**0件**。
  C1未実装時に見られた「トランス接続直後の数分間、ハイインピーダンスノードが
  広帯域ノイズを拾ってフルスケールに張り付く」挙動(→
  [2026-08-07-fs-wiring-verification.md](2026-08-07-fs-wiring-verification.md))が消えた
- 振幅は l_pp 相当で約43%FS。C1実装前の実測(約48%FS)と同程度で、分圧設計自体は
  変わっていないことと整合する
- **基本波 50.015Hz、THD(2〜7次)=0.0%**。綺麗な正弦波のまま
- ゼロクロス周波数 median=49.938Hz, std=0.277Hz(参考値。ゼロクロス法自体の精度は
  主張しない。→ [signal-processing.md](../signal-processing.md))

## 何が可能になったか

`docs/hardware.md`のAFE回路図・C1の項を「未確定」から確定値(15nF)に書き換えた。
残るAFEの未確定事項はTVS(サージ対策)のみ。
