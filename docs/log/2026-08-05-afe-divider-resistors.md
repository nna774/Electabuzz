# 2026-08-05 AFE 分圧抵抗を R1=100kΩ / R2=6.8kΩ に確定

トランス二次側の DMM 再測定
（[別セッションが先に着手・merge 済みだったコミット](https://github.com/nna774/Electabuzz/commit/beaa944)。
実効値 10.3 VAC = 29.1 Vpp、分圧設計は変更なしと結論済み）で無負荷出力の不確かさが
解消されたのを機に、`hardware.md` に「PCM1808 データシートのフルスケール入力から
逆算する」とだけ書かれて具体値が無かった AFE 分圧抵抗を計算した。

## 分かったこと

TI の PCM1808 データシート(`pcm1808.pdf`)の `Electrical Characteristics` /
`ANALOG INPUT` 表から:

- **Input voltage = 0.6 VCC Vp-p**（フルスケール）
- **Center voltage (VREF) = 0.5 VCC**
- **Input impedance = 60kΩ(typ.)**

`Recommended Operating Conditions` の VCC=5V 行にも「Analog input voltage, full
scale = 3 Vp-p」と明記があり、0.6×5V と一致する。**VCC=5V を前提にフルスケール
3.0Vpp** として計算した。

## 決めたこと

**R1=100kΩ、R2=6.8kΩ(E24標準品)に確定した。**

設計上のワーストケース入力 34Vpp(`hardware.md` の既存の想定値)に対し、素の分圧比
(k≒0.0637)では分圧後 2.17Vpp = FS比72%。**ADC の入力インピーダンス 60kΩ(typ.)が
R2 と並列に効く**ことを見落とすと過大評価になるので、これを含めた実効分圧比
(k≒0.0576)で再計算すると 1.96Vpp = FS比65%。実測の無負荷出力 29.1Vpp では
FS比56〜62%で、いずれもクリップから十分な余裕がある。

R1 を「数十kΩ〜100kΩ」のレンジの上限である100kΩ側に寄せたのは、`hardware.md` に
既にあった「万一の異常時にも電流が流れない設計にする」という方針を優先したため。

## まだ決めていないこと

**LPF(C1)・TVS・Vcc/2 バイアスの具体的な定数、および OP アンプの型番は未確定のまま
残した。** Sallen-Key の2次LPFは OP アンプが要る回路なので、抵抗分圧だけを先に
確定させても筋が悪くない(分圧比は OP アンプの選定と無関係に決まる)。
`bom.md` の当該行は「未確定」と明示して分けた。

## 次に何が可能になったこと

R1/R2 は E24 の一般品なので、買っても手戻りが起きない。**OP アンプを選んでから
LPF 定数を計算する**のが次の一手。
