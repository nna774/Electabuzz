# 2026-08-03: AC入力部が確定した

## 決めたこと

**Ideal Power DA-12-09（トランス式AC出力アダプタ）を AC入力部として採用する。**
100V/50Hz・周囲30℃・無負荷で1時間通電し、三項目すべて合格した。

| 検証項目 | 結果 | 判定 |
|---|---|---|
| 温度上昇 | 検出限界以下。1時間後、床・室温と区別がつかない | 合格 |
| 唸り | 耳を筐体に密着させてやっと聞こえる 100Hz。濁りのない澄んだ音 | 合格 |
| 波形 | 素直な正弦波。クリップ・整流痕・飽和の折れ曲がり無し | 合格 |
| 無負荷出力 | Vpp = 29.61V（3回測定で 0.01V 以内）。実効値 約 10.5 VAC | 想定より高い |

## なぜこれで結論できるのか

**三つの独立した物理量が同じ結論を指したからだ。** 音・熱・波形はいずれも磁束密度の指標で、
どれも「磁束は線形領域の余裕ある位置にある」と言っている。
設計書の V/f = 1.00× という机上計算が、三方向から裏付けられた。

**温度は熱量計として読める。** 熱抵抗 ≈ 6 K/W に対し ΔT が検出限界（1〜2K）以下ということは、
**無負荷損失は 0.2W 未満**である。鉄損は B のおよそ2乗で効くので、
これ自体が磁束の低さの定量的な上界になっている。

熱時定数 ≈ 15分に対し1時間は約4時定数、**98% 平衡に到達済み。追加の観測は不要。**

**30℃ の周囲温度で通したことに意味がある。** 真夏の室内は年間で最も条件が悪い。
ここで通れば一年中通る。冬に試験しても夏の保証にはならないが、逆は成立する。

## 覆ったこと

- **無負荷出力が想定（8〜9 VAC / 25 Vpp）より高い 10.5 VAC / 29.6 Vpp だった。**
  分圧比を引き直す。ただし回路構成は変わらず、元よりヘッドルームを取る設計なので吸収される
- **50Hz 定格品への退避案（77DS-06-xy 等）は不要になった。** プラグ変換アダプタを
  24/7 常設の最弱点として抱える必要がなくなった

## 副産物: 手持ち測定器の信頼度が確定した

同じ信号を3回測った結果から、何を信じて何を捨てるべきかが決まった。

| 読み | 実測での挙動 | 方針 |
|---|---|---|
| Vpp の再現性 | 3回で 29.60 / 29.61 / 29.61 | 信じる |
| 波形の形 | 3回とも同じ正弦波 | 信じる（粗大な歪みの有無のみ） |
| Vpp の絶対値 | 垂直未校正、±5〜10%見込み | DMM で裏を取る |
| DC レベル (Vavr) | 10.54 → 8.51 → 8.92 と漂流 | 捨てる |
| 周波数 | **50.049 / 51.334 / 50.050 Hz** | **絶対に使うな** |

**原則: 安価な測定器は絶対確度より再現性がずっと良い。比較と形状に使い、絶対値には使うな。**

**これは本プロジェクトの存在理由の実演になっている。** 手元の測定器は 1mHz の分解能を
表示しながら 1Hz を保証できない。「自分の確度を示せない測定器は測定器ではない」が
そのまま目の前にあった。

## 次に何が可能になったか

- 分圧比の設計。**DMM の到着を待たなくてよい**（29.6 Vpp に ±10% の不確かさがあっても吸収される）
- オシロのクリップを何も考えずに出力へ繋げたのは**トランスで絶縁されているから**である。
  代替A（ZMPT101B を AC100V に直結）を採っていたら同じ操作が接地への短絡になっていた。
  「測定器を気軽に当てられる」ことが絶縁を選んだ判断の実際的な意味だ
