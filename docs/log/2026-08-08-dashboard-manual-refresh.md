# ダッシュボードに手動更新ボタンを足した

自動更新は`/recent`をポーリングするたびにAPI呼び出し(=費用)が発生する。Namazu側の
ダッシュボード（イベント一覧・デバイス一覧タブ）には自動更新のON/OFFに関わらず
常時「再読み込み」ボタンがあり、同じ形をElectabuzzの唯一のグラフにも足した。

`dashboard/index.html`に「更新」ボタンを1つ追加し、`dashboard/app.js`で既存の
`refresh()`にクリックイベントを繋いだだけ。**自動更新チェックボックスの状態で
ボタンの表示・非表示を切り替える必要はない**——自動更新オンの間に手動更新を
押しても実害はなく（`refresh()`を1回余計に呼ぶだけ）、出し分けはコードが増える
わりに得るものがない。

`refresh-now`ボタンを追加しただけで、ローディング状態・二重クリック防止等は
実装していない。`refresh()`自体が短時間で完了するAPI呼び出し1つで、Namazu側の
「再読み込み」ボタンも同様の作りのため、対称性を優先した。
