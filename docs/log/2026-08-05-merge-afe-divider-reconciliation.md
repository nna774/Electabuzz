# 2026-08-05 main の分岐マージ: AFE 分圧抵抗の前提を実測 VCC で検算

`main` とリモートの `main` が並行セッションで分岐していた。一方（このセッション）は
[PCM1808 の現物とデータシートを突き合わせるログ](2026-08-05-pcm1808-arrival.md)の続きで
`VCC` を ESP32 の `5V` ピンから取ると決め、実測 4.84V（公称 5V ではない）に合わせて
分圧の目標を「フルスケールの 60〜75%」というレンジへ緩めていた。もう一方
（[別セッション](https://github.com/nna774/Electabuzz/commit/b68166f)）は同じ頃に
VCC 公称 5V 前提で R1=100kΩ/R2=6.8kΩ に確定していた。`docs/hardware.md` と
`docs/progress.md` で衝突した。

## 分かったこと

両者は矛盾していない。R1/R2 の確定値と、VCC 実測値という2つの独立した情報を
そのまま合成できた。確定済みの R1=100kΩ/R2=6.8kΩ を実測 VCC=4.84V で検算すると:

- 分圧比 k = R2/(R1+R2) ≒ 0.0637。ADC の入力インピーダンス 60kΩ(typ.) が R2 と並列に
  効くため、実効分圧比は k ≒ 0.0576 まで下がる（この点は origin 側の計算のまま）
- フルスケールは実測 VCC ベースで 0.6×4.84 = 2.904Vpp（公称 5V なら 3.0Vpp）
- ワーストケース入力 34Vpp に対する FS比: 公称 VCC=5V では 72%(素の分圧比)/65%(ADC負荷込み)
  だったが、実測 VCC=4.84V では **74.5%/67.4%** とやや上がる
- 実測の無負荷出力 29.1Vpp では FS比 57.7〜63.8%

**75% の天井にはまだ余裕があり、R1/R2 の再選定は不要。** ただしワーストケースの上限が
公称値の想定より天井に近づいた事実は残しておく価値があると判断し、`hardware.md` に明記した。

## 決めたこと

- `docs/hardware.md` の AFE 分圧設計の節を1本化した。R1=100kΩ/R2=6.8kΩ の確定値と、
  VCC が ESP32 の `5V` ピン実測 4.84V であるという事実を両方残し、FS比を実測 VCC で
  再計算した数値に置き換えた
- 検討したが採らなかった E12 の代替比の表（68k+68k/10k 等）は「意図的に採らなかった選択肢」
  として残した
- `docs/progress.md` は両ブランチの 2026-08-05 の行を時刻順に並べ直し、この検算の結果を
  最上段に1行足した
- `docs/open-questions.md` の `v_rms_mv` の行にあった「分圧比は 1/14、DMM 実測待ち」という
  記述は、マージ前から既に(このマージとは無関係に)二重に古くなっていたので、確定値を指す
  記述に直した

## 次に何が可能になったこと

AFE の抵抗値は VCC の実測を織り込んでも確定のままなので、買っても手戻りが起きない。
残るのは LPF・TVS・Vcc/2 バイアスの定数と OP アンプの選定（両ブランチとも未確定のまま）。
