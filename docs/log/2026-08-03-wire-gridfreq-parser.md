# 2026-08-03 `wire_gridfreq.py` を書いた — 形式の契約が往復で閉じた

`lambda/wire_gridfreq.py` と `lambda/tests/test_wire_gridfreq.py`（20件、緑）。
**書き手（firmware）と読み手（Lambda）が揃い、ゴールデンフィクスチャを両側から
主張する形になった。**片側からしか検証されていない契約はもう無い。

開発環境として **repo 直下に `.venv` を作った**（Namazu と同じ形。今は pytest だけ。
`NtpTimebase` に入るとき platformio もここへ入れる）。

## 決めたこと

### 「読めない」と「壊れている」を別の型にする

`WireFormatError` と `CrcMismatch`（後者は前者の派生）。
**形式違いは設定の事故、CRC 不一致は中身の事故**であり、後者だけ「隔離して次へ進む」が
正しい対処になる。同じ例外にすると、呼び出し側がメッセージ文字列で判定する羽目になる。

### `NAMZ` の magic を名指しで弾く

```
NAMZ batch (地震計) が GFRQ の ingest に届いている: デバイスの kIngestUrl 誤設定を疑え
```

独自 magic にした目的がこれだ。**「意味不明なデータ」ではなく「設定ミス」として報告する。**
弾けるだけでは半分で、**何を直せばいいかまで言えて初めて fail-fast の値打ちが出る。**

### 末尾の余りは黙って読み飛ばさない

`GFRQ` v1 に tail は無い。余りがあるのは連結・切り詰めの事故だ。
tail を使う版を作るなら `version` を上げればよく、**今のパーサが寛容である理由が無い。**

### 未知の `timebase_source` を「規正済み」と名乗らせない

`is_disciplined` は既知の `NTP`/`PPS`/`PPS+NTP` にだけ True を返す。
将来 `4 = OCXO` のような源が増えたとき、古いパーサはそれを False と見る。
**保守的すぎる側に外れるのは正しい。** ここが True に倒れると
「測れなかった区間を測れたように見せない」という一線が**パーサ側から**破れるからだ。

同じ理由で `f_nominal_mhz` の既定を 0 にしてある（firmware 側の判断）。
**書き手と読み手の両方で、分からないものは主張しない方に倒した。**

### `te_seconds()` はバッチ内の相対 TE だけ返す

絶対 TE はセッションを跨いだ基準が要るので出さない（`cycles` は「セッション開始からの
絶対値」であって「標準時からのずれ」ではない）。**バッチ内に閉じている限り
うるう秒の1秒ジャンプを踏まない** — 時刻を `batch_start_us` からの式で作り、
区間の途中で UTC を読み直さないからだ。危ないのはバッチを跨いで繋ぐ側で、そちらは
連続時系で扱う（→ [timebase.md](../timebase.md)）。

### 依存は stdlib だけ

1バッチ30レコードに numpy を持ち出す理由が無い。持ち込まなければ ingest Lambda の zip に
platform wheel の面倒（`--platform` と `--only-binary` の組み合わせ制約）が入らない。
**Namazu が numpy を要るのは波形処理があるからで、こちらは事情が違う。**

## 分かったこと

**形式の分解能がテストで数字になって出た。** 「1秒あたり 50.01 サイクル」を食わせて TE を
見ると、期待値との差が最大 0.11µs 残る。これは誤差ではなく **2^-16 サイクル固定小数点の
量子化そのもの**（50Hz で 0.31µs）で、レコードにそれ以上の情報が入っていない。
テストの許容もその量子で書いた。**「なぜ合わないか」が形式から説明できる差は、
許容を緩めるのではなく理由を書く。**

## 次に何が可能になったか

- **`ingest` Lambda** — パースと検証が在るので、あとは S3 へ置く経路だけ。
  ただし**キー命名 `{device:04d}-{batch_start_us:020d}.bin` は必ず踏襲する**
  （20桁ゼロ埋めゆえに辞書順 = 時系列順。`batch-uplink` の `s3util` がそのまま使える）
- **`NtpTimebase`** — 母艦が刺されば着手できる。`.venv` に platformio を入れるところから
