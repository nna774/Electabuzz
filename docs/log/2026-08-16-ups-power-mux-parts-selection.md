# UPS(乾電池バックアップ)電源マルチプレクサの部品選定・配線・容量計算

## 背景

[2026-08-11](2026-08-11-usb-ups-power-mux-design.md)で「電源マルチプレクサIC(TPS2113A系)+乾電池バックアップ」の方向性は決まっていたが、**型番・配線・出力コンデンサ容量・昇圧要否は未検証のまま**残っていた。本セッションでそれぞれ具体化した。

## 1. キャリアボードの実物を確定した

[Switch Science #7017](https://www.switch-science.com/products/7017)がPololu製TPS2113Aキャリアボード(POLOLU-2596、¥1,793)そのものだと確認した。`STAT`・`EN`・`ILIM`・`VSNS`も引き出されており、2026-08-11ログの計画(STATを停電フラグに使う)がそのまま実現できる。

## 2. 配線の落とし穴: OUTはESPの`3V3`ではなく`5V`ピンへ

当初「OUTをESPの`GND`/`3.3V`に直結すればよいか」という問いが出たが、これは危険。

- **OUTはレギュレータではなくパススルー。** 選ばれた入力の電圧がそのまま(MOSFETの微小抵抗降下のみで)出る
- **このボードの`micro-B USBコネクタはデフォルトでIN1に直結**(Pololu公式ページで確認)。USBを挿せばIN1は生の5V(VBUS)になる
- 自動切替モード(デフォルト、`VSNS`未使用時)は**IN1/IN2のうち電圧が高い方を選ぶ**——USB接続中は当然IN1(5V)が勝つ

つまりOUTはUSB接続中は5V近辺になる。これを`3.3V`ピン(ESPのロジック直結、絶対最大定格3.6V程度)に繋げば**USB接続中に壊れる**。

**正しい配線: `OUT`→ESPの`5V`ピン。** ESP32 DevKitの5V→3.3Vオンボードレギュレータに丸投げする(PCM1808のVCCを同じ5Vピンから取っているのと同じ発想)。

## 3. 昇圧要否の判断が変わった

2026-08-11時点では「マルチプレクサの入力下限(2.8V)に電池電圧が収まれば昇圧は省略できるかもしれない」という仮説があった。しかし上記の配線(`OUT`→ESPの`5V`ピン、`IN1`=USB生5V)を採る以上、**IN2(電池側)もESPのオンボードレギュレータが3.3Vを安定して出せる電圧(概ね4.3〜4.6V以上)を用意する必要がある**——単3を数本直列にしただけでは、放電が進むにつれてこの下限を割り込む。**昇圧(正確には昇降圧)コンバータは必要、という結論に戻った。**

ただし2026-08-11で「昇圧を常時通電すると待機中に電池を消耗する」と指摘した無負荷消費電流(Iq)の問題は、部品選定で解決できた(次項)。

## 4. 昇降圧モジュールの選定

候補に上がった[Strawberry Linux #12015](https://strawberry-linux.com/catalog/items?code=12015)(LT1615、¥990)は**却下**。無負荷Iq≤40µAは理想的だが、最大出力電流が軽負荷50mA〜中負荷100-200mA止まりで、母艦(ESP32-S3+GNSS、WiFi送信バーストで数百mAオーダーまで跳ねる想定)の負荷には桁が足りない。

**採用候補: Pololu S9V11F5**([switch-science](https://www.switch-science.com/products/3246/)、¥2,332)。

| 項目 | 値 |
|---|---|
| 入力電圧 | 2〜16V(起動に3V要、動作継続は2Vまで) |
| 出力 | 5V固定 |
| 最大出力電流 | Vin≈5V付近でtyp 1.5A |
| 無負荷Iq | **`Vin<7V`でtyp <100µA** |
| 効率 | >90% |
| サイズ | 7.6×11.4×3.8mm |

単3×4本(新品6.4V〜末期4V)は丸ごと`Vin<7V`のIq<100µA帯に収まり、出力電流も1.5A>>0.5A(想定ピーク)で余裕がある。前回指摘した「Iqと電流容量はトレードオフ」の中で両方を満たす個体として妥当と判断した。

より大電流(2A)・広入力(2.9〜32V)が欲しければ**Pololu S18V20F5**(Iq typ 1mA)も選択肢にあるが、今回の規模ではS9V11F5の方がサイズ・Iqとも分がいい。

## 5. 出力側バルクコンデンサのオーダー計算

TPS2112A/TPS2113Aデータシート(TI SBVS045C)の`SWITCHING CHARACTERISTICS`表から、自然なUSB抜線に該当する経路(`IN2-IN1`コンパレータ経由の自動切替、`EN`ピンのdisable/enableを介する経路とは別物でこちらは1〜5msと大幅に遅い)のスペックを確認した:

- **Transition time (`t_T`)**: typ 40µs / max 60µs(条件: `C_L=10µF`、`I_L=500mA`)

`ΔV = I・Δt / C`に、想定ピーク負荷`I=0.5A`・`Δt=60µs`(max)・許容ドループ`ΔV=0.3V`(仮置き、下流レギュレータの実ドロップアウト未測定)を入れると

```
C = 0.5A × 60µs / 0.3V ≒ 100µF
```

**オーダーとしては100〜220µF級の電解/タンタルコンデンサ1個で足りる計算。** ただし`ΔV=0.3V`という許容値自体が仮置きであり、**実機組み立て後にOUT端子をスコープで見て抜線時のドループを直接確認する**のが最終確認になる(データシート値を鵜呑みにしない、という既存方針通り)。

## 6. 単3×4本での稼働時間試算

母艦の消費電力見積り(`docs/hardware.md`、**未実測**の1W級)とS9V11F5の効率(90%)から:

```
電池側で引く電力 ≒ 1W ÷ 0.9 ≒ 1.11W
```

**アルカリ単3×4本**(容量2000〜2500mAh・放電中平均パック電圧≈4.8Vで見積り):

```
エネルギー ≒ 9.6〜12Wh → 稼働時間 ≒ 8.6〜10.8時間
```

**リチウム一次電池(Energizer Ultimate Lithium級)**(容量3000mAh・電圧が終盤まで垂れにくく平均5.5Vで見積り):

```
エネルギー ≒ 16.5Wh → 稼働時間 ≒ 約15時間
```

`docs/hardware.md`の既存記述(10000mAh級Li-ionモバイルバッテリーで「数十時間」)と比較すると、37Wh程度に対し単3×4本は9.6〜16.5Whと1/3〜1/4程度のエネルギー量で、稼働時間もほぼ比例して短くなっており整合する。**2026-08-11ログの「リチウム一次電池を検討する価値がある」という判断は、保存性だけでなく実際の稼働時間でも裏付けられた。**

## 結論

- 部品は**Pololu-2596(TPS2113Aキャリア、switch-science #7017)+ Pololu S9V11F5(昇降圧、switch-science)**の組み合わせで妥当
- 配線は**マルチプレクサの`OUT`→ESPの`5V`ピン**(`3V3`ピンへの直結は厳禁)
- 出力バルクコンデンサは**100〜220µF程度**が計算上の目安(実機での要確認は残る)
- 単3×4本アルカリで**8〜11時間**、リチウム一次電池で**約15時間**の稼働が見込める(いずれも母艦消費電力1W見積りに依存した概算)

**ただし本セッションは検討・計算のみで、発注・実装はまだ行っていない。** 母艦の実消費電力測定(`docs/bom.md`のUSB電力計)・実機でのコンデンサドループ確認・部品発注が次のステップとして残る。

## 追記: 手持ちの鉛蓄電池が死んでいた件と、代替案の検討

同セッション中、ユーザーが「ソーラーパネル充電テスト用に買って放置していた12V鉛蓄電池」を候補に挙げたが、HIOKI 3244-60でOCVを実測したところ**0.76V**だった。6セル直列で1セルあたり0.13V相当であり、通常の自己放電で到達する範囲(健全なら10V台、深放電でも10.5V程度が目安)を大きく下回る。**深放電が長期化し、いずれかのセルで内部短絡(サルフェーション由来のデンドライトによるプレート間ショート)が発生し実質死んでいると判断した。** 通常の充電器を繋ぐのは危険(短絡箇所への電流集中で発熱)なので推奨せず、処分(鉛蓄電池はリサイクル回収)を勧めた。**単3×4本+リチウム一次電池という元の計画に戻る形になった。**

これを受けて「リチウムを安全に充電する設計が面倒」という声が出たため、**代替として「コンセント直結型モバイルバッテリー」(AC差込プラグ内蔵、壁に挿すだけで充電+パススルー給電をこなす製品カテゴリ)を調査した。**

- 同種の用途(Raspberry PiのUPS化)を先に試した記事を発見: [Raspberry Piに最適なミニUPSを探し](https://zenn.dev/ureo/articles/mini-ups-for-pi)(Zenn、著者: ureo)。**RAVPower RP-PB125(6700mAh、AC直結)で「瞬断なし」の切替を確認したと報告されている。** 軽負荷での自動遮断が起きうる製品もある中、この製品はパススルー用途で問題なかったという実例
- RAVPowerはブランドとしての現在の経営状態が不透明なため、**現行の入手性は要確認**。同カテゴリで入手性が安定してそうな代替として**Anker PowerCore Fusion 5000**(5000mAh、AC直結)も挙げた
- この製品カテゴリを使えば、**リチウム充電回路の自作(保護IC・セルバランス等)が丸ごと不要になる**——充電制御はメーカー側で完結済み。かつ「常時パススルー」がコンセプトの製品なので、通常のモバイルバッテリーで懸念される「軽負荷での自動出力オフ」も原理的に起きにくい

**「TPS2113A + コンセント直結型モバイルバッテリー」の組み合わせも検討したが、今のフェーズでは見送りと判断した。** 理由:

- コンセント直結型バンク単体で既に「AC入力→内蔵電池へのシームレス切替」を完結しており、TPS2113Aを足す価値は主に①ACアダプタ自体の単体故障への冗長化 ②STATによる機械可読フラグ、の2点に限られる
- ①は停電より発生頻度が低い故障モードへの保険で、TPS2113A自体が新たな単一障害点になる代償と釣り合うか怪しい
- ②のSTATフラグは「IN1経路が死んだ」ことしか分からず、**停電なのかACアダプタ故障なのかは区別できない**——[open-questions.md](../open-questions.md)ですでに整理した「AC入力線抜けと停電が原理的に区別できない」問題と同じ形の限界を持つ。しかもフェーズ9(クラウド側detect)が未着手で、フラグを取っても現時点では消費先が無い

**結論(暫定、決定ではない): 単一機のホビープロジェクトとしては、コンセント直結型モバイルバッテリー単体(TPS2113A無し)の方が複雑さに見合う。STATフラグが必要になったら足せばよく、部品コスト(¥1,793程度)も低いので後回しにできる。** 鉛蓄電池同様、この節も検討止まりで発注・実装はしていない。
