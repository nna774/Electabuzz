# PCM1808 モジュール（缶発振器なし版）を発注した

## 何を決めたか

PCM1808 I2S ADC モジュールを購入した。缶発振器（12.288MHz オシレータ）を**搭載していない版**。

- 商品: https://www.amazon.co.jp/dp/B09BTLPBM4

## なぜそう決めたか

[open-questions.md](../open-questions.md) の「購入時に確認すること」にあった問い
（缶発振器の有無 = どちらが SCKI の master になるか）は、Amazon の商品写真では
判定できなかった。だが検討の結果、**判定を待つ必要が無いと分かった**。

- [timebase.md](../timebase.md) の通り、**方式Aは SCKI の master がどちらでも成立する**
  （クロック誤差が一次で相殺される）。缶発振器の有無は正しさに影響しない
- 今 GNSS・PPS 配線がまだ無い段階なら、後で構成を変えても**フェーズ1.5 の `fs` 実測を
  やり直すだけ**で済む。[risks.md](../risks.md) リスク10 が禁じているのは
  **PPS 到着後**の構成変更（検証全体のやり直しになる）であって、今の時点ではない
- 「缶発振器なし」構成は ESP32 が MCLK を出す前提になる。これは元々 **S3 を採用した
  理由**（無印 ESP32 は MCLK 出力が GPIO 0/1/3 に限られる）と整合している

## 何が次に可能になるか

PCM1808 到着後、AFE(分圧 + LPF)を繋いで I2S 配線し、**フェーズ1.5 の `NtpTimebase` で
この構成（ESP32-as-SCKI-master）の `fs` 実測と安定度評価**ができる。

[risks.md](../risks.md) リスク10 の「両構成を実測して決めろ」を満たすには、
缶発振器**あり**のモジュールも別途確保して比較する必要がある。**あり版は未購入のまま**。
安価な部品なので、比較したくなった時点で追加すればよい（→ [open-questions.md](../open-questions.md)）。
